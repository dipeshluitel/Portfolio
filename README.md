# Portfolio Website

**Personal Developer Portfolio Website**  
This is my personal portfolio website built with **Django** and **Bootstrap**. It showcases my skills, projects, experience, and contact information in a clean and responsive layout.

🔗 **Live Demo:** https://dipeshluitel.com.np

---

## 💡 About

This portfolio website is designed to highlight my web development skills and projects.  
It is built using the **Django Web Framework**, styled with **Bootstrap**, and organized with modern HTML, CSS, and Python backend logic.

The site is fully responsive, mobile-friendly, and easy to customize.

## 🚀 Getting Started (Local Setup)

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/dipeshluitel/Portfolio.git
cd Portfolio
```

### 1. Clone the repository

```bash
git clone https://github.com/dipeshluitel/Portfolio.git
cd Portfolio
```

### 2. Create & activate a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate   # (Mac/Linux)
# or
venv\Scripts\activate      # (Windows)

```


### 3.Install dependencies

```bash
pip install -r requirements.txt

```

### 4. Apply Migrations 

```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Run Development Server
```bash
python manage.py runserver
```
